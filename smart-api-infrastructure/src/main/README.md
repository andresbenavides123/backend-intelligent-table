# Backend Intelligent Table

Backend desarrollado para la plataforma Intelligent Table.

## 🚀 Tecnologías utilizadas

- Java
- Spring Boot
- Maven
- MySQL
- REST API

## 📂 Funcionalidades

- Gestión de usuarios
- Gestión de datos inteligentes
- API REST
- Conexión con frontend
- Persistencia en base de datos

## ⚙️ Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/andresbenavides123/backend-intelligent-table.git
```

2. Abrir el proyecto en IntelliJ IDEA o VS Code.

3. Configurar la base de datos.

4. Ejecutar:

```bash
mvn spring-boot:run
```

# 🚀 Backend Intelligent Table

<p align="center">
  Backend desarrollado para la plataforma <strong>Intelligent Table</strong>.
</p>

---

## 📋 Descripción del Proyecto

Este proyecto corresponde al backend de la plataforma Intelligent Table, encargado de la gestión lógica, procesamiento de datos y comunicación mediante servicios REST API.

El sistema permite administrar información de manera eficiente y segura utilizando arquitectura basada en Spring Boot.

---

## 🛠️ Tecnologías Utilizadas

- ☕ Java
- 🌱 Spring Boot
- 🛢️ MySQL
- 📦 Maven
- 🔗 REST API

## ⚙️ Instalación y Ejecución

### 1️⃣ Clonar repositorio

```bash
git clone https://github.com/andresbenavides123/backend-intelligent-table.git
```

### 2️⃣ Entrar a carpeta

```bash
cd backend-intelligent-table
```

### 3️⃣ Ejecutar proyecto

```bash
mvn spring-boot:run
```
